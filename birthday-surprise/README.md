# Birthday Surprise Website

A cinematic, magical birthday surprise website built as a static HTML/CSS/JS project.

## Included

- 3D-inspired floating gift and hero scene
- Decorative photo cards using the local project images
- Gift-opening interaction and candle-blowing experience
- Photo gallery with rotating, polaroid, and timeline layouts
- Personalized love letter and star wishes
- Countdown, music controls, and finale fireworks
- Responsive layout for desktop and mobile

## Files

- `index.html` — page structure
- `style.css` — styling and animations
- `script.js` — interactivity and effects
- `config.js` — personalization settings
- `assets/photos/` — project photos used as decorative memory art

## Customize

Edit the content in `config.js`:

- `name`
- `birthdayDate`
- `message`
- `finalMessage`
- `photos`
- `reasons`
- `wishes`
- `theme`

## Local testing

From the project folder:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```

## GitHub Pages deployment

1. Push this folder to a GitHub repository.
2. In GitHub, open the repository settings.
3. Go to Pages.
4. Select the source branch and root folder.
5. Save and wait for deployment.

## Vercel deployment

1. Import the project into Vercel.
2. Set the root directory to the project folder.
3. Use the default static site settings.
4. Deploy.

## Notes

The site uses the project photos as 3D-style decorative pieces, not as full-size album images, to match your request.
